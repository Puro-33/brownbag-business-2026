# 경영학부, 그다음은?

2026년 11월 5일 브라운백 전공간담회 경영학부 사전 질문 21개를 정리한 읽기 전용 웹 페이지입니다.

첨부 자료의 다듬은 답변을 바탕으로 구성했습니다. 원본 채팅은 공개하지 않았습니다. 답변은 멘토 개인 경험과 의견으로 학교의 공식 안내가 아닙니다. 교과과정, 졸업요건, 취업률 등은 별도로 검증하지 않았습니다.

GitHub Pages: main 브랜치, 루트 폴더에서 배포합니다. 외부 라이브러리·서버·환경변수·추적 스크립트가 필요하지 않습니다. 검색엔진 제외 요청(noindex)을 포함하지만 비공개나 접근제한을 의미하지 않습니다.
